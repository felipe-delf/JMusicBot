
# JMusicBot

Discord Music Bot desenvolvido em Java com Spring Boot.

## Objetivo

O JMusicBot permitirá que usuários reproduzam músicas em servidores Discord,
com suporte a pesquisa no YouTube, playlists do YouTube e playlists do Spotify.

## Tecnologias

- Java 21
- Spring Boot
- JDA
- Lavalink
- Maven
- PostgreSQL
- Docker
